设置与备份

V1.7 延用 V1.1 本机数据库，不会覆盖 V1.0 旧数据。如需使用旧数据，可从 V1.0 导入，旧人物会先作为第二层关系人，之后再逐个调整。

备份与恢复

普通 JSON 包含真实姓名及联系方式，建议优先使用加密备份。请勿将备份传到公开 GitHub 仓库。换手机或清除网站数据可能导致资料丢失。

从 V1.0 迁移

可读取同一网址、同一浏览器环境内的旧版数据库；不会修改旧数据。迁移时所有旧人物先按第二层导入，由你手动指定专业资源的下层关系。
